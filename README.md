# 🐥 메추리

> 오늘 뭐 먹지?  
> 메추리가 점심 메뉴를 골라줄게요.

메추리는 직장인과 자영업자의 점심 메뉴 고민을 줄여주는  
**게임형 메뉴 추천 앱**입니다.

랜덤 추천, 음식 성향 테스트, 밥운세, 룰렛 기능을 통해  
메뉴 선택을 가볍고 재미있게 해결하는 것이 목표입니다.

---

## 핵심 기능

### 1. 오늘의 메뉴 추천

사용자의 기분/상황에 따라 메뉴를 추천합니다.

예시 선택지:

- 가볍게
- 든든하게
- 매콤하게
- 랜덤으로

---

### 2. 음식 성향 테스트

MBTI처럼 간단한 질문에 답하면 음식 성향을 분석합니다.

예시 결과:

- 국밥 안정형
- 제육 추진형
- 샐러드 관리형
- 돈까스 행복형
- 마라 모험형

---

### 3. 오늘의 밥운세

운세처럼 오늘의 메뉴를 추천합니다.

제공 정보:

- 음식 운세 점수
- 행운의 메뉴
- 행운의 색깔
- 추천 한마디

---

### 4. 메뉴 룰렛

여러 메뉴 후보 중 하나를 룰렛으로 결정합니다.

예시 카테고리:

- 한식
- 중식
- 일식
- 양식
- 분식
- 패스트푸드

---

## MVP 범위

초기 버전에서는 아래 기능만 구현합니다.

- 홈 화면
- 오늘의 메뉴 추천
- 음식 성향 테스트
- 테스트 결과 화면
- 오늘의 밥운세
- 메뉴 룰렛
- 결과 공유하기

---

초기 MVP에서는 제외합니다.

- 로그인

- 배달앱 연동
